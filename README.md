
# Python Conditional Logic Exercises

## Overview

This folder contains a set of beginner Python exercises created as part of my learning journey toward becoming a **Junior Malware Analyst**.

The focus of these exercises is understanding **conditional logic**, which is a fundamental concept in programming and an essential skill when analyzing how software (including malware) makes decisions and controls execution flow.

---

## Concepts Practiced

Through these exercises, I practiced:

* `if` / `else` statements
* Boolean values (`True` / `False`)
* Logical operators (`and`)
* Conditional (ternary) expressions
* Writing clean, readable, and well-commented code

---

## Files Overview

* **`temperature_check.py`**
  Demonstrates basic `if/else` logic using user input.

* **`age_eligibility.py`**
  Shows how variables and conditional statements can be used to determine program output.

* **`logical_operators.py`**
  Uses multiple conditions and logical operators to control decision-making.

Each file is self-contained and can be run independently.

---

## Why This Matters for Malware Analysis

Conditional logic is heavily used in malware to:

* Check system or user conditions
* Decide whether to execute certain behaviors
* Change execution paths dynamically

Learning how to read and write condition-based logic helps build the foundation needed for:

* Static code analysis
* Understanding execution flow
* Reverse engineering decision-making logic in malicious software
